<Info>
  **Before you install: enable the MCP in your Klarity workspace.**

  1. Log in to Klarity in a browser.
  2. Go to **Settings → MCP**.
  3. Pick the workspace you want to expose to your assistant and complete the in-app setup.

  Sign-in will fail if you skip this. See [Authentication → Enable the MCP in your workspace](/authentication#enable-the-mcp-in-your-workspace) for the canonical reference, and [FAQ](/faq) for other common install issues.
</Info>

Two install paths are supported. The plugin path is preferred — it ships the bundled skill prompt and uses OAuth.

## Plugin install (preferred, OAuth)

From a Codex session:

```text
/plugin marketplace add klarity-ai/klarity-mcp
/plugin install klarity@klarity
```

The first request that hits a Klarity tool will prompt you to sign in.

## Config file install (API key)

Generate an API key from `Settings → MCP` in your Klarity workspace (see [Authentication](/authentication#api-key)). Add the server to `~/.codex/config.toml`:

```toml
[mcp_servers.klarity_architect]
url = "https://architect-v2-api.klarity.ai/mcp"
bearer_token_env_var = "KLARITY_ARCHITECT_MCP_TOKEN"
```

Set the environment variable in your shell profile (`~/.zshrc`, `~/.bashrc`):

```bash
export KLARITY_ARCHITECT_MCP_TOKEN=<YOUR_API_KEY>
```

Restart your terminal (or source the profile) so Codex picks up the new variable.

<Warning>
  Treat the API key like a password. Rotate it from `Settings → MCP` in Klarity if it's exposed.
</Warning>

## Verify

In a Codex session, ask:

```text
Search Klarity for AI transformation opportunities across our processes — where could we build skills or deploy agents?
```

The assistant should call `search` and return process results from your workspace.

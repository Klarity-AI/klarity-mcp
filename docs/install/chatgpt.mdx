<Info>
  **Before you install: enable the MCP in your Klarity workspace.**

  1. Log in to Klarity in a browser.
  2. Go to **Settings → MCP**.
  3. Pick the workspace you want to expose to your assistant and complete the in-app setup.

  Sign-in will fail if you skip this. See [Authentication → Enable the MCP in your workspace](/authentication#enable-the-mcp-in-your-workspace) for the canonical reference, and [FAQ](/faq) for other common install issues.
</Info>

Once the Klarity app is live in the OpenAI App Store:

<Steps>
  <Step title="Open the app picker">
    In ChatGPT, click **Apps**.
  </Step>
  <Step title="Find Klarity">
    Search for **Klarity** and click **Connect**.
  </Step>
  <Step title="Sign in">
    You'll be redirected to Klarity to authenticate. The assistant can then query your active workspace.
  </Step>
</Steps>

<Note>
  Your organization may need to approve the app first, and you must be provisioned as a user in Klarity for the connection to succeed.
</Note>

## If you don't have access

If your organization hasn't approved the Klarity app yet, or you can't see it in ChatGPT's app picker, you can still connect from any of the other install paths. Each supports OAuth, an API key, or both — pick whichever client you already have:

- [Claude Code](/install/claude-code) — OAuth via the plugin, or Bearer-token MCP add
- [Codex](/install/codex) — OAuth via `codex mcp login`, or `config.toml` with a Bearer token
- [Cursor](/install/cursor) — OAuth via the **Connect** button, or `.cursor/mcp.json` with a Bearer header
- [Gemini CLI](/install/gemini-cli) — OAuth via `/mcp auth`, or env-based Bearer token

The data and permissions are identical regardless of how you connect.

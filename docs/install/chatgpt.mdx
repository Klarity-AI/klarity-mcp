Once the Klarity app is live in the OpenAI App Store:

<Steps>
  <Step title="Open the app picker">
    In ChatGPT, click **Apps**.
  </Step>
  <Step title="Find Klarity">
    Search for **Klarity** and click **Connect**.
  </Step>
  <Step title="Sign in">
    You'll be redirected to Klarity to authenticate. The assistant can then query your active workspace.
  </Step>
</Steps>

<Note>
  Your organization may need to approve the app first, and you must be provisioned as a user in Klarity for the connection to succeed.
</Note>

## API key fallback

If the app is not yet approved in your org or you need a Bearer token for a custom setup, see [Authentication → API key](/authentication#api-key).

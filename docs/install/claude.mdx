Once the Klarity connector is live in Anthropic's official directory:

<Steps>
  <Step title="Open connector settings">
    In Claude, go to **Customize → Connectors**.
  </Step>
  <Step title="Find Klarity">
    Search for **Klarity** and click **Connect**.
  </Step>
  <Step title="Sign in">
    You will be redirected to Klarity to authenticate. Your assistant will then have access to your active workspace.
  </Step>
</Steps>

<Note>
  Your organization may need to approve the connector first, and you must be provisioned as a user in Klarity for the connection to succeed.
</Note>

## API key fallback

If your organization has not approved the connector yet, or you need a Bearer token for a custom setup, see [Authentication → API key](/authentication#api-key).
